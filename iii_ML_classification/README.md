Nuclear protein image datasets are written using Step 12_1 in Folder i. A nuclear image dataset of eight classes (cell types) demonstrated in our study can be downloaded from [10.5281/zenodo.18633455](https://doi.org/10.5281/zenodo.18633455) to demonstrate Step 12 MONAI classifier training (train/val/test dataset splits), iv QuAC analysis, and v QuAC feature quantitation. Place "QUAC_images" extracted folder in the same directory of these codes. The demonstration dataset has train/val/test splits.

A Step 12 MONAI classifier training for only train and val dataset splits (no test split) is also available, suitable for smalle image datasets.
